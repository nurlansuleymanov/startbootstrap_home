# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and Bootstrap**.  
This project recreates the design style of the Start Bootstrap Personal template while implementing custom styling and UI elements from scratch.

## 🚀 Project Overview

This project was created to practice frontend development fundamentals and Bootstrap usage.

The main focus was:
- Building a clean webpage structure with HTML
- Creating responsive layouts with Bootstrap Grid System
- Styling components with custom CSS
- Working with gradients, positioning, and decorative elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## ✨ Features

✅ Responsive navigation bar  
✅ Hero section with gradient typography  
✅ Custom image background design  
✅ CSS pseudo-elements (`::before`, `::after`) for decorations  
✅ Bootstrap buttons and layout utilities  
✅ About section with social media icons  
✅ Simple footer section
